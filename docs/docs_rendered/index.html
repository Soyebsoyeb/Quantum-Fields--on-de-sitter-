1. Overview

This repository investigates quantum fields on a prescribed, classical, four-dimensional de Sitter spacetime. It follows a deliberate ladder of increasing physical content, and every rung is derived, implemented, and independently checked before the next one is built:

classical action  ->  Klein-Gordon equation  ->  mode equation  ->  canonical quantization
      ->  vacuum state  ->  Wightman / Green functions  ->  UV and IR structure
      ->  lambda phi^4 interaction  ->  in-in perturbation theory  ->  tree-level correlator
      ->  secular growth and perturbative validity  ->  tensor modes (boundary with quantum gravity)

What this project is

  • A symbolically derived pipeline: curvature, field equation, conformal-time equation and mode equation are produced by SymPy and compared with the closed forms, not typed in from memory.
  • A numerically validated pipeline: every numerical result has an independent analytic or non-perturbative cross-check with a stated tolerance.
  • A reproducible pipeline: every figure comes from an importable function, every run writes a JSON record containing parameters, tolerances, diagnostics, a data hash and software versions.

What this project is not

  • It is not a theory of quantum gravity. The metric is a fixed classical background; quantizing a test scalar does not quantize the geometry. See Section 4.11.
  • It is not a complete renormalized treatment. One point-splitting subtraction is implemented with its scheme dependence made explicit; no covariant Hadamard renormalization, no loop renormalization of the coupling.
  • It does not present any numerical plot as a proof. Each result carries one of six classifications (below).

Three charts that must not be conflated. The global chart covers the whole hyperboloid; the spatially flat expanding chart used for all numerics covers half of it and is past-incomplete (so η→−∞ is a coordinate horizon, not a Cauchy surface); the static patch covers one observer's causal diamond. A "state at η→−∞" is therefore a statement about mode behavior near the chart boundary.

The de Sitter invariant in the flat chart is

Z=2ηη′η2+η′2−r2​,r=∣x−x′∣,

with Z=cos(Hσ) for spacelike geodesic separation σ. The correctness of this expression is itself tested: the mode-sum and closed-form Wightman functions agree to 10−13 only if it is right.

4.2 Action, Klein-Gordon equation, conformal time

S[ϕ]=−21​∫d4x−g​[gμν∇μ​ϕ∇ν​ϕ+(m2+ξR)ϕ2] ⟹ (□−m2−ξR)ϕ=0.

The variation produces the boundary term ∮dΣμ​δϕ∇μϕ, which vanishes for δϕ=0 on the boundary hypersurfaces. In the flat chart:

ϕ¨​+3Hϕ˙​−a2∇2​ϕ+(m2+12ξH2)ϕ=0,ϕ′′+2aa′​ϕ′−∇2ϕ+a2(m2+ξR)ϕ=0.

The friction term 3Hϕ˙​=∂t​ln−g​ϕ˙​ is the dilution of field momentum density by the growth of comoving volume. The conformal-time equation is derived from the covariant d'Alembertian and independently cross-checked by the chain rule ∂t​=a−1∂η​ (both are asserted in the tests).

Implemented in: scalar_action.py (euler_lagrange_vs_klein_gordon, conformal_time_equation, cosmic_time_equation_difference, cosmic_to_conformal_chain_rule).

4.4 Canonical quantization and the Wronskian

For χ=aϕ the momentum is πχ​=χ′; equivalently πχ​=πϕ​/a+(a′/a)χ, so [χ^​,π^χ​]=[ϕ^​,π^ϕ​]=iδ(3). With

χ^​=∫(2π)3d3k​[a^k​vk​eik⋅x+h.c.],[a^k​,a^k′†​]=(2π)3δ(3)(k−k′),

the equal-time commutator holds if and only if vk​vk∗′​−vk∗​vk′​=i. For a real second-order ODE this Wronskian is η-independent, so numerically it is a pure measure of integration error.

Basis versus state. A Bogoliubov-related basis uk​=αvk​+βvk∗​ with ∣α∣2−∣β∣2=1 preserves the algebra but defines a different Fock vacuum. A mode basis is data used to construct a Fock space; the state is the one annihilated by the attached a^k​. The repository never rescales a solution after integration: normalization.check_normalization only reports residuals.

Bunch-Davies (BD). The Fock vacuum of the mode that is positive-frequency at the chart's early boundary. It coincides with the Euclidean vacuum, is SO(1,4)-invariant where the two-point function exists (Chernikov-Tagirov, Bunch-Davies, Allen), and is one member of the one-parameter α-vacuum family. For ν≥3/2 the BD two-point function is infrared divergent and, at ν=3/2, no de Sitter-invariant Fock vacuum exists at all (Allen-Folacci).

Hankel-free confirmation. initial_conditions.adiabatic_data builds WKB adiabatic vacua of order 0, 2, 4 from W2=ω2−[W′′/2W−3W′2/4W2] iterated symbolically. Evolving them numerically converges to the analytic BD mode as ∣η0​∣→∞, faster at higher order (Fig. 3c). This shows independently that the positive-frequency condition selects the BD state.

4.6 Wightman function and propagators

G+(η,η′,r)=⟨Ω∣ϕ^​(x)ϕ^​(x′)∣Ω⟩=2π21​∫0∞​dkk2ϕk​(η)ϕk∗​(η′)krsinkr​,ϕk​=vk​/a.

This is a bi-distribution: at equal times the integrand falls only as k−1. The prescription used (Abel summation, not a cutoff) subtracts and restores the conformal-vacuum piece ∣vk​∣2→1/2k, whose transform is exactly 1/(4π2r2):

G+(η,r)=H2η2[4π2r21​+2π2r1​∫0∞​dkk(∣vk​∣2−2k1​)sinkr],

with the remainder integrable like k−2 and evaluated by QUADPACK QAWF.

verified three ways: as a solution of the de Sitter-invariant ODE (1−Z2)G′′−4ZG′−(49​−ν2)G=0 (relative residual ∼10−30), by reduction at ν=1/2 to H2ηη′/[4π2(r2−Δη2)], and against the mode sum (∼10−13).

4.7 Ultraviolet structure and renormalization

With u=(1−Z)/2=sin2(Hσ/2), the connection formula of 2​F1​ with c=a+b−1 (DLMF 15.8.10) gives

G+=uA​+Blnu+C+O(ulnu),A=16π2H2​,B=(49​−ν2−2)A,C=B[ψ(23​+ν)+ψ(23​−ν)+2γE​−1].

B is independently recovered by a Frobenius recursion of the invariant ODE; all three coefficients are confirmed numerically (residual ∝ulnu, Fig. 6b). Because u≃H2σ2/4, the leading singularity is 1/(4π2σ2): the flat-space form, independent of mass, coupling and state (Fig. 6a).

Hadamard condition (conceptual, [C]). A state is Hadamard if G+=8π21​[Δ1/2/σ2+Vlnσ2+W] with V fixed locally by geometry and m,ξ, and only the smooth W carrying state information (equivalently a wavefront-set condition, Radzikowski). Hadamard states are those for which Wick polynomials and ⟨Tμν​⟩ can be defined consistently. BD is Hadamard; generic α-vacua are not (antipodal singularities). The full Hadamard recursion is not implemented.

A numerical cutoff is not a renormalization. For ν=3/2 with a comoving cutoff, ⟨ϕ2⟩Λ​=4π2H2​[lnkIR​Λ​+2η2Λ2​] (exact; Fig. 6c): a quadratic divergence in physical units plus a log, a cutoff that breaks de Sitter invariance, no counterterm and no scheme.

The one explicit subtraction implemented (two_point.coincident_phi2_pointsplit):

⟨ϕ2⟩μ​≡σ→0lim​[G+−4π2σ21​−Bln(μ2σ2)]=3A​+C+Bln4μ2H2​.

Finite ambiguities, all stated and tested: the scale μ; the choice of subtracting 1/4π2σ2 rather than the full parametrix (the factor Δ1/2=(Hσ/sinHσ)3/2≃1+H2σ2/4 shifts the constant by H2/16π2); and renormalization conditions for m2 and ξ. For the conformal case B=C=0 and the result H2/48π2 is μ-independent. This is not presented as a unique renormalized value.

4.8 Infrared structure

For real ν>0, Hν(1)​(x)≃−πi​Γ(ν)(2/x)ν as x→0, hence ∣ϕk​∣2∝k−2ν and ∫dkk2−2ν converges at k→0 iff ν<3/2.

  • ν=3/2: frozen spectrum, and the variance of modes between an IR scale kIR​ and the horizon grows linearly, ⟨ϕ2⟩=4π2H2​N (that is H3t/4π2).
  • ν<3/2 with m≪H: since 23​−ν≃m2/3H2, growth saturates after N∼3H2/2m2 e-folds near 3H4/8π2m2.

Independent benchmark. The point-split ⟨ϕ2⟩ tends to 3H4/8π2m2 as m→0 (through ψ(23​−ν)→−1/(23​−ν)), matching the stationary solution Peq​∝exp[−8π2V/3H4] of the Starobinsky Fokker-Planck equation. For V=λϕ4/4! the same equilibrium gives ⟨ϕ2⟩≈0.3228H2/λ​ (numerical, λ=1), which is non-perturbative in λ and cannot be reproduced by a fixed-order series.

Distinguish an IR-divergent intermediate expression from an ill-defined prediction. Shift-invariant observables (derivative correlators, field differences) are IR finite even at ν=3/2; the kIR​ dependence of ⟨ϕ2⟩ reflects the state or patch size. By contrast, the absence of an SO(1,4)-invariant state at ν=3/2 is a theorem-level statement, not a cutoff artifact.

4.9 Interactions and the in-in formalism

Sint​=−∫d4x−g​4!λ​ϕ4,[λ]=0 (verified in code).

The interaction has no derivatives, so πϕ​=a2ϕ′ is unchanged and the Legendre transform gives Hint​=−Lint​=a44!λ​ϕ4=4!λ​χ4, explicitly time-independent for any m and ξ: all time dependence lives in the mode functions (verified symbolically).

Why in-in rather than in-out. The expanding patch has no late-time asymptotic region with a free-particle interpretation (η→0− is a spacelike boundary). Cosmological observables are equal-time expectation values in a given initial state, not transition amplitudes:

⟨Q(η)⟩=⟨Ω​Tˉei∫−∞η​HI​QI​(η)Te−i∫−∞η​HI​​Ω⟩ O(λ)​ i∫−∞η​dη′⟨[HI​(η′),Q(η)]⟩=−2Im∫dη′⟨HI​(η′)Q(η)⟩.

Schwinger-Keldysh contour: time-ordered branch (vertices −iHI​) and anti-time-ordered branch (vertices +iHI​) joined at the final time; the iϵ (Abel) prescription at η→−∞ projects the free vacuum onto the interacting one. The two branches are returned separately by in_in.schwinger_keldysh_branches and sum to the commutator form (tested).

Assumptions stated explicitly: free BD initial state; adiabatic switch-on; derivative-free vertex so HI​=−LI​; first order in λ. Different initial states or start times give different perturbative series.

Independent validation of the formula. The 0+1-dimensional analogue H=p2/2+ω2q2/2+gq4/4! obeys the identical formula, κ4(1)​=−g/(32ω5), where κ4​=⟨q4⟩−3⟨q2⟩2. Exact diagonalization of the ground state in a truncated oscillator basis reproduces the slope to a relative error of 1.6×10−6 (Fig. 11), fixing sign and normalization without any field-theory machinery.

4.10 Tree-level contact correlator and secular growth

Specification (all items required by the project brief): vertex −i4!λ​χ4 (contact); external modes vki​​; time range (−∞,η]; free BD vacuum; Fourier measure (2π)3δ(3) stripped; order λ1; contour rotation η′=η−(1+i)s as the convergence prescription.

⟨ϕk1​​⋯ϕk4​​⟩conn′​=−2λH4η4 Im[i=1∏4​vki​∗​(η)∫−∞η​dη′i=1∏4​vki​​(η′)].

Derivation sketch. The 4! ways of contracting the four vertex fields with the four external fields cancel the 1/4!; each contraction is vk​(η′)vk∗​(η); momentum conservation comes from ∫d3x; converting the external legs from χ to ϕ gives a−4=H4η4. Vertex self-contractions are tadpole or disconnected pieces and are not part of the connected correlator.

Analytic limit (validation). For ν=1/2 with K=∑ki​,

⟨ϕ4⟩conn′​=−8K∏i​ki​λH4η4​​

reproduced numerically to 3×10−16 (Fig. 9a). The η4 scaling is a−4: conformal invariance means the interaction does not evolve in conformal variables.

Massless minimal field (nu = 3/2): the secular logarithm. Expanding ϕk​(η′)=2k3​H​(1+2k2η′2​−3ik3η′3​+…), the η′3 term in a4∏ϕ yields ∫dη′/η′, so

⟨ϕ4⟩conn′​ η→0−​ 24∏i​ki3​λH4∑i​ki3​​ln(−η)+const.

For the tested momenta (1,1.3,0.7,1.1) the coefficient is 0.2023507, matched numerically with relative error below 10−6 (Fig. 9c).

Perturbative validity (numerical experiment, Fig. 10). The ratio R=⟨ϕ4⟩conn(1)​/Pk2​ (equal momenta) behaves as follows:

nu Behavior in N=ln(1/k∣η∣) Interpretation
1/2 constant (−λ/8) conformal invariance, no growth
1, 5/4 saturates massive suppression, scale set by 1/(23​−ν)
3/2 grows linearly secular term: fixed-order expansion degrades when λN∼1

This signals the breakdown of the fixed-order expansion, not an inconsistency of the theory. Resummation (Starobinsky stochastic dynamics; Starobinsky-Yokoyama; Marolf-Morrison; Hollands) controls the IR sector. Those methods are described, and the equilibrium variance is used as a benchmark, but they are not derived here.

4.11 Tensor perturbations and the boundary with quantum gravity

With ds2=a2[−dη2+(δij​+hij​)dxidxj] and vacuum equations Rμν​=Λgμν​, the plus polarization hxx​=−hyy​=ϵh(η,z) is plugged into the SymPy Ricci tensor. The background residual vanishes and

δ(Rxx​−Λgxx​)=21​ϵ[h′′+2aa′​h′−∂z2​h] ⟹ hk′′​−η2​hk′​+k2hk​=0.

With the standard quadratic action S2​=8Mp2​​∫dηd3xa2[(hij′​)2−(∂k​hij​)2] (quoted from the literature), hij​=∑λ​eijλ​hλ​ and eijλ​eijλ′​=2δλλ′, the variable vλ​=Mp​ahλ​/2​ is a massless minimally coupled scalar (ν=3/2) and

Δt2​=2π2k3​⟨hij​hij​⟩′=π2Mp2​2H2​.

Numerical integration reproduces the full x=−kη dependence and the late-time plateau (Fig. 12).

What changes when the metric itself is quantized (conceptual, [C]):

  • A test scalar has δgμν​=0. Quantizing hμν​ makes the geometry an operator and the scalar's Tμν​ sources it, giving O(G) corrections from matter-gravity and graviton self-interaction vertices.
  • Gauge fixing (for example de Donder, with Faddeev-Popov ghosts) or reduction to gauge-invariant variables is required; the Hamiltonian and momentum constraints remove unphysical components. De Sitter has no spatial infinity and no globally defined energy, so there is no standard S-matrix.
  • General relativity is perturbatively non-renormalizable ('t Hooft-Veltman; Goroff-Sagnotti) but is a valid effective field theory below Mp​ (Donoghue), with corrections of order H2/Mp2​ and contested de Sitter infrared issues.

Explicitly not claimed: that quantizing a scalar quantizes gravity; any graviton loop; any solution of the non-perturbative de Sitter quantum-gravity problem.

6. Validation strategy

The guiding rule: no result is trusted because one code path produced it. Each quantity is verified by a second, structurally different route, and tests are designed to fail when the physics is wrong (negative controls).

6.2 The 17 programmatic checks (desitter-qft validate)

Symbolic: R=12H2 in three charts; Euler-Lagrange equals −g​(□−m2−ξR)ϕ; cosmic-time equation with 3Hϕ˙​; conformal equation versus chain rule; rescaled mode equation; de Sitter reduction; tensor equation. Numeric and analytic: Hankel Wronskian; Hankel ODE substitution; closed form versus Hankel at ν=3/2; DOP853 versus analytic; mode sum versus closed form; invariant-ODE residual; QM in-in slope; conformal contact correlator. Results are archived in results/validation.json with tolerances.

6.3 Negative controls (tests that must be able to fail)

  • Wrong normalization: 2v has Wronskian 4i and the checker flags residual 3.
  • Wrong curvature sign convention: asserting R=−12H2 fails.
  • Wrong ξ: the closed-form conformal mode does not solve the minimally coupled equation (residual >0.1).
  • Wrong sign of the in-in slope would fail the exact-diagonalization comparison.
  • Bogoliubov coefficients violating ∣α∣2−∣β∣2=1 break the Wronskian (notebook 06).
  • Hash sensitivity: perturbing data by 10−6 changes the recorded hash.

6.4 What the numerics do and do not establish

Numerical agreement validates, but does not prove, the analytic statements. A plot is never used as a proof; each figure is accompanied by the analytic or independent result it checks.

7. Results and figures

All figures are generated by desitter-qft all and saved as PNG and PDF. Each caption states the claim and its classification.

7.1 Geometry and horizon crossing (Fig. 1) [A, S]

The comoving Hubble radius 1/(aH)=−η shrinks, so every comoving scale 1/k eventually exits the horizon (k∣η∣=1). The map t↦η(t) shows η→0− as t→∞ (the future boundary).

7.2 Modes, solver convergence and the vacuum (Figs. 2-3) [A, N]

(a) Maximum relative error versus analytic mode scales linearly with rtol over nine decades for RK45, DOP853 and Radau before saturating near 10−12 (round-off). (b) The Wronskian residual follows the same scaling and is never rescaled. (c) Hankel-free adiabatic initial data of order 0, 2, 4 converge to the analytic BD mode as ∣η0​∣ grows, faster at higher order: the positive-frequency boundary condition independently selects the BD state.

Recorded diagnostics (results/free_modes.json, rtol 10−11, DOP853, k=1, η∈[−80,−0.02]):

7.3 Power spectra and freeze-out (Fig. 4) [A, N]

The dimensionless spectrum Δϕ2​=2π2k3​∣ϕk​∣2 freezes at H2/4π2 for ν=3/2, decays as x3−2ν for real ν<3/2 (grey: analytic Hankel asymptote), and decays with log-periodic oscillation for imaginary ν.

7.4 Wightman function: mode sum versus closed form (Fig. 5) [A, N]

The Abel-regularized mode sum (markers) reproduces the hypergeometric closed form (lines) to 10−13 for real ν and 10−9 for imaginary ν. This tests the Hankel normalization, the Fourier convention and the invariant Z simultaneously.

7.5 Ultraviolet structure (Fig. 6) [A, N]

(a) The leading singularity is the flat-space 1/(4π2d2) for all ν. (b) The expansion A/u+Blnu+C leaves a residual scaling as ulnu (the conformal case has B=C=0 and is omitted: its residual is round-off). (c) A sharp comoving cutoff gives the exact Λ2 divergence plus a logarithm: a diagnostic of divergence structure, not a renormalization.

7.6 Infrared variance (Fig. 7) [N]

For ν=3/2 the variance grows as N/4π2; for light massive fields it saturates near 3H4/8π2m2 (dotted, leading order in m/H). The m=0.6H plateau (0.096H2) differs from the leading-order estimate (0.105H2) by the expected subleading corrections.

7.7 Propagators (Fig. 8) [A, N]

(a, b) The retarded function from Hankel modes agrees with an independent Hankel-free ODE solution to 4×10−12 and has derivative jump 1.0000000001. (c) The Feynman function is continuous at coincidence with a slope kink of −i and ReGF=ReG+.

7.8 Tree-level contact correlator (Fig. 9) [P, N]

(a) Conformal case: numerical in-in integral versus the analytic −λH4η4/(8K∏ki​). (b) Real-axis Abel-damped integrals converge linearly in ϵ to the rotated-contour value. (c) Massless minimal case: numerical correlator against the derived logarithmic slope.

7.9 Secular growth and perturbative validity (Fig. 10) [N]

Conformal: constant. Massive: saturating. Massless minimal: linear in N, so the fixed-order result degrades for λN∼1. This is a statement about the expansion.

7.10 In-in versus exact diagonalization (Fig. 11) [P]

The exact fourth cumulant approaches the first-order in-in line as g→0 with a relative deviation scaling as g (next order), fixing the sign and normalization of the in-in formula.

7.11 Tensor spectrum (Fig. 12) [S, A, N]

Numerical integration of the tensor mode equation reproduces the analytic ν=3/2 spectrum and its plateau 2H2/(π2Mp2​)=0.2026424 (numerical 0.2026426 at x=10−3).

8. Numerical methods in detail

Component Method Notes
Mode ODE scipy.integrate.solve_ivp, default DOP853 (also RK45, Radau) state (Rev,Imv,Rev′,Imv′); rtol 10−4-10−13, atol about 10−2 rtol or 10−13
Scaling vk​(η)=k−1/2f(kη) all numerics at k=1
Hankel functions scipy.special.hankel1, jv, yv for real order; mpmath.hankel1 for imaginary order derivative via DLMF 10.6.2
Hypergeometric and Gamma mpmath.hyp2f1, gamma, digamma 30-40 digits
Distributional k-integral QUADPACK QAWF (weight='sin') on the tail, ordinary QAGS on the head Abel-regularized by subtracting 1/2k
In-in time integral contour rotation η′=η−(1+i)s, split at geometric breakpoints double precision (scipy.quad) or 40-digit mpmath.quad
WKB initial data symbolic iteration, lambdified even orders 0, 2, 4
Exact diagonalization scipy.linalg.eigh in an oscillator basis (up to 140 states) g>0 only (bounded potential)

Known precision hazards, handled explicitly.

  • Late-time in-in: the imaginary part is a difference of quantities of magnitude ∼(k∣η∣)−7 for ν=3/2; double precision would lose most digits, so contact_correlator defaults to the 40-digit mpmath backend for ν∈{1/2,3/2} and a test cross-checks both backends elsewhere.
  • Wronskian growth: the residual scales with ∣v∣∣v′∣; for the tensor mode at η=−10−3 it reaches about 2×10−7 at rtol 10−12. This is reported, never hidden by rescaling.
  • Imaginary-order Hankel evaluation through mpmath limits tail-integral accuracy to about 10−11 absolute, so imaginary-ν position-space tests stop at r≤5.

9. API guide

9.1 Solve and audit a mode

from desitter_qft.mode_equations import ModeEquation, regime
from desitter_qft.initial_conditions import adiabatic_data
from desitter_qft.numerical_solver import solve_mode
from desitter_qft.normalization import check_normalization
from desitter_qft.analytic_modes import bunch_davies_mode

eq = ModeEquation(k=1.0, m=0.8, xi=0.0)           # nu = 1.2689 (real: complementary series)
print(eq.nu, regime(eq.nu2))

v0, dv0 = adiabatic_data(eq, eta0=-100.0, order=4)  # Hankel-free WKB initial data
sol = solve_mode(eq, -100.0, -0.05, v0, dv0, rtol=1e-11, atol=1e-13)

rep = check_normalization(sol.eta, sol.v, sol.dv, rtol=1e-11, atol=1e-13, method="DOP853")
print(rep.max_residual, rep.passes)                 # about 4.5e-11, True (no rescaling applied)

ref = abs(bunch_davies_mode(sol.eta[-1], 1.0, eq.nu))**2
print(abs(sol.v[-1])**2 / ref - 1)                  # about -1.2e-11: converged to Bunch-Davies

10. Reproducibility and provenance

Every experiment writes a record to results/ with:

  • model parameters, initial conditions, integration interval, solver method and tolerances;
  • numerical precision and error diagnostics (Wronskian reports, maximum residuals, function-evaluation counts);
  • data_sha256: a SHA-256 of the output arrays rounded to 10 decimals, insensitive to last-bit noise;
  • software versions captured at run time (Python, NumPy, SciPy, SymPy, mpmath, Matplotlib).

Determinism is tested: repeated runs of the quartic-oscillator and tensor experiments give identical hashes, and a 10−6 perturbation changes the hash. There is no randomness anywhere in the code. reports/technical_report.md section 17 is generated from the JSON records by scripts/build_report.py, so the report cannot drift from the code.

12. Scope, limitations and honesty statement

Implemented and validated: free scalar for real, marginal and imaginary nu; Wightman function and short-distance structure; mode-space Green functions; first-order tree-level contact correlator; tensor modes on a fixed background.

Explicit limitations:

  1. Fixed four-dimensional de Sitter, spatially flat chart only. The BD state is a statement about the chart boundary, not an initial condition on a complete Cauchy surface.
  2. For ν≥3/2 the BD two-point function is infrared divergent; results with a cutoff depend on it.
  3. Point-splitting constants are scheme dependent and are not claimed to be unique or fully covariant.
  4. Secular growth signals the breakdown of the fixed-order expansion, not an inconsistency of the theory.
  5. Double-precision Hankel evaluation loses digits at late times for generic nu; mpmath is used where it matters.
  6. The tensor-action normalization is quoted from the literature and validated by reproducing the standard spectrum; it is not rederived symbolically from the Einstein-Hilbert action.
  7. Numerical agreement validates but does not prove analytic statements.

Metadata caveats:

  • references.bib was written from bibliographic knowledge and has not been machine-verified against Crossref or INSPIRE. Verify volume, page and DOI fields before citing.
  • CITATION.cff and LICENSE contain placeholders for author name and repository URL. Fill them before publishing.

14. Extending the code, and optional third-party libraries

The repository currently depends only on NumPy, SciPy, SymPy, mpmath and Matplotlib (plus pytest and the notebook stack for development). Third-party libraries are welcome for the research directions above. None of the following are currently used; they are suggestions, each tied to a concrete bottleneck:

Adding a new observable, in four steps: derive the expression in a docs/ file with its assumptions; implement it in the package with a docstring giving its classification tag; add an independent check (second analytic route or non-perturbative benchmark) and at least one negative control in tests/; register a programmatic check in validation.py and an experiment in experiments.py so that the figure, JSON record and report update together.
