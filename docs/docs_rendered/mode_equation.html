Derivation

Put ϕ=v/a and ∇2→−k2 in the conformal-time equation. Using ϕ′=v′/a−a′v/a2,

ϕ′′+2aa′​ϕ′=av′′​−a2a′′​v.
Inserting R=6a′′/a3 so that a2ξR=6ξa′′/a:
vk′′​+[k2+a2m2+(6ξ−1)aa′′​]vk​=0.
Why rescale? Writing χ=aϕ in the action and integrating by parts removes the friction term:
S=21​∫dηd3x[χ′2−(∇χ)2−(a2m2+(6ξ−1)aa′′​)χ2].
This is a flat-space scalar with a time-dependent mass: canonical momentum πχ​=χ′, so canonical commutators and the Wronskian are those of a unit-mass oscillator.

Benchmarks

  • Conformal, m=0,ξ=1/6 (ν=1/2). 6ξ−1=0 and m=0: the time-dependent term vanishes, v′′+k2v=0, v=e−ikη/2k​. ϕ=v/a=−Hηv. This is the statement that the massless conformally coupled field is Weyl-equivalent to a flat-space massless field; the in-in vertex a4ϕ4=χ4 is then time-independent.
  • Massless minimal, m=0,ξ=0 (ν=3/2). v′′+(k2−2/η2)v=0, v=2k​e−ikη​(1−kηi​), ϕk​=2k3​H​(1+ikη)e−ikη→2k3​H​. Super-horizon modes freeze with a scale-invariant spectrum Δϕ2​=H2/4π2 (Fig. 4). IR subtlety: ∫dkk2∣ϕk​∣2∼∫dk/k diverges at small k. The formal mode expansion does not define a de Sitter-invariant state: there is no SO(1,4)-invariant Hilbert-space vacuum for this field (Allen–Folacci 1987); see infrared_structure.md.
  • Massive, general ν. As above; light fields (ν<3/2) decay super-horizon, with ϕk​∝(−η)3/2−ν, i.e. Δϕ2​∝x3−2ν (grey asymptotes in Fig. 4).

Numerical comparison

solve_mode integrates the real ODE from η0​=−80 to −0.02 using exact BD data; max abs error ≲2×10−9 (Fig. 2), error ∝ rtol over 8 decades (Fig. 3a). Using adiabatic (WKB) initial data of order 0/2/4 instead of Hankel data, the numerical solution converges to the analytic BD mode as ∣η0​∣→∞ with higher order giving faster convergence (Fig. 3c): this is a Hankel-free confirmation that the positive-frequency boundary condition selects the same state.
