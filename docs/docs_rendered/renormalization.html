Renormalisation

Status: conceptual discussion + one explicitly specified point-splitting subtraction. No claim of a fully renormalised, covariant result.

Conceptual role

Divergences of ⟨ϕ2⟩, ⟨Tμν​⟩ and of loop corrections are local: they are absorbed by counterterms built from local curvature invariants and the couplings (m2, ξ, λ, Λcc​, G, higher-curvature terms). A renormalisation condition fixes the finite parts; different conditions differ by finite local terms, e.g. ⟨ϕ2⟩→⟨ϕ2⟩+c1​m2+c2​(ξ−61​)R+c3​μ-dependent. These ambiguities are physical inputs (measured couplings), not defects, but a number quoted without its scheme is meaningless. Covariant schemes: Hadamard point splitting (Wald 1977; Hollands–Wald 2001; Birrell–Davies 1982).

The example implemented: ⟨ϕ2⟩ by point splitting

Definition (two_point.coincident_phi2_pointsplit):

⟨ϕ2⟩μ​≡σ→0lim​[G+(σ)−4π2σ21​−Bln(μ2σ2)].
Using A/u=H2σ24A​+3A​+O(σ2) and lnu=ln(H2σ2/4)+O(σ2):
⟨ϕ2⟩μ​=3A​+C+Bln4μ2H2​.
Checks: for ν=1/2 (B=C=0) ⟨ϕ2⟩=A/3=H2/48π2 for any μ; for m→0 with ξ=0, →3H4/8π2m2 (test), reproducing the leading IR physics.

Finite renormalisation ambiguities (explicit):

  1. μ: shifts the result by Bln(μ2/μ02​) (tested).
  2. Subtracting the full Hadamard parametrix with Δ1/2 rather than the bare 1/(4π2σ2) shifts the constant by A=H2/16π2 (Δ1/2=(Hσ/sinHσ)3/2≃1+H2σ2/4 in d=4 gives a constant offset) — a different but equally legitimate scheme.
  3. A term ∝m2 or (ξ−61​)R from the choice of renormalisation condition for m2,ξ.

What is NOT done: a covariant (non-coordinate) Hadamard subtraction with the full local V recursion; ⟨Tμν​⟩; any loop renormalisation of λ (beta function βλ​=3λ2/16π2 in flat space is quoted knowledge, not computed here; on dS curvature corrections and the IR sector alter the effective running and are not treated); no number from this file should be compared to literature values without reconciling the scheme. This is why README and the report label it as scheme-specific.
