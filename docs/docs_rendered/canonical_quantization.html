Mode basis vs state

Another basis uk​=αk​vk​+βk​vk∗​ with ∣α∣2−∣β∣2=1 gives the same operator algebra and the same Wronskian; the corresponding annihilation operators are Bogoliubov transforms b^=α∗a^−β∗a^†. Different bases define different Fock vacua ∣0v​⟩=∣0u​⟩ (inequivalent in general), hence different states. A mode basis is data used to build a Fock space; the state is the one annihilated by the a^k​ attached to the chosen basis.

Numerical normalisation checker

check_normalization returns the pointwise residual, initial/final/max residual and location, growth factor, solver settings, and a pass/fail against 103rtol. No rescaling. Observed behaviour: with exact initial data the residual stays at the 10−11 level for moderate ∣v∣∣v′∣; for modes that grow like 1/∣η∣ (massless minimal, η→−10−3) the absolute residual rises to ∼10−7 at rtol =10−12 because the residual scales with ∣v∣∣v′∣∼109 — accuracy loss that is reported, not hidden (tests/test_tensor.py).
