Propagators and Green functions

Status: analytic definitions; mode-space identities verified numerically (propagators.py, Fig. 8). Position-space Feynman function: defined, not implemented.

For the operator Dk​=∂η2​+wk2​(η) acting on χk​ and a normalised BD mode vk​:

Function Definition Equation Boundary condition
Wightman G+=v(η)v∗(η′) DG+=0 state-dependent (BD)
Feynman GF=θ(η−η′)v(η)v∗(η′)+θ(η′−η)v∗(η)v(η′) DGF=−iδ(η−η′) BD positive-frequency (the iϵ at η→−∞)

Delta strengths. The derivative jump across η=η′ is, for GR: i(v′v∗−v∗′v)=i(−i)=1; for GF: v′v∗−v∗′v=−i (uses W=i). Hence the signs above.

State independence. GR=−2θIm[v(η)v∗(η′)] is built from the commutator ⟨[χ^​(η),χ^​(η′)]⟩=vv∗′-antisymmetrisation, a c-number fixed by the CCR; every normalised mode basis (every Fock vacuum) gives the same GR. GF and G+ do depend on the state.

Position space

The position-space Feynman function is the distribution GF=θG++θ′G−; its singularity at x=x′ is the same as in flat space: 4π21​σ2+iϵ1​-type, so coincident limits are not finite numbers (see ultraviolet_structure.md). We therefore never evaluate G(x,x) without a stated subtraction.
