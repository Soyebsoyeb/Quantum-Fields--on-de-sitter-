Time variables

Cosmic time t, a=eHt. Conformal time dη=dt/a, i.e. η=−1/(Ha)=−e−Ht/H∈(−∞,0) and a(η)=−1/(Hη). Overdots are d/dt, primes d/dη. a′/a=−1/η, a′′/a=2/η2, H≡a′/a=aH.

Numerical conventions

  • IEEE binary64 unless stated. mpmath (40 digits) is used for (i) Hankel functions of imaginary order, (ii) hypergeometric closed forms, (iii) the late-time in-in integrals where cancellations destroy double precision.
  • ODE solver: scipy.integrate.solve_ivp, default DOP853, rtol=1e-10…1e-12, atol≈1e-2·rtol or 1e-13. State vector (Rev,Imv,Rev′,Imv′).
  • Every solution is reported with the Wronskian residual ∣vv∗′−v∗v′−i∣. Nothing is rescaled after integration.
  • Mode-function numerics use k=1; the equation depends on k only through kη (scaling vk​(η)=k−1/2f(kη)).
  • Result classification (used in docs, docstrings and results/*.json): (1) analytic result, (2) symbolic verification, (3) numerical experiment, (4) perturbative approximation, (5) conceptual discussion, (6) unimplemented direction.
