# Conformal time

$d\eta=dt/a\Rightarrow\eta=\int^t e^{-Ht'}dt'=-\dfrac{e^{-Ht}}{H}=-\dfrac1{Ha}$, choosing the integration constant so that $\eta\to0^-$ as $t\to\infty$ (future infinity $\mathscr I^+$). The metric becomes $ds^2=a^2(\eta)(-d\eta^2+d\mathbf x^2)$, conformally flat; null geodesics are straight lines at $45^\circ$, so causal structure is that of the half-Minkowski region $\eta<0$.

Useful identities (symbolic, `mode_equations.de_sitter_reduction`):
$$a=-\frac1{H\eta},\quad \frac{a'}{a}=-\frac1\eta,\quad \frac{a''}{a}=\frac2{\eta^2}.$$
The number of e-folds between $\eta_1<\eta_2$ is $N=\ln(\eta_1/\eta_2)$. A mode exits the horizon at $\eta_k=-1/k$; "$N$ e-folds after exit" means $\eta=-e^{-N}/k$ (the horizontal axis of Figs. 7, 9, 10).
